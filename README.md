# アクアリュウム

Delta Chatのチャットで金魚を育てるwebxdcアプリです。金魚をお迎えし、お世話や友だちの金魚との交流を楽しめます。

現在の配布版：**1.0.2**

## まず使ってみる

### Delta Chatで使う

1. `aquaryuum-1.0.2.xdc` をチャットへファイルとして送信します。
2. 届いたアプリのメッセージを開きます。
3. 読み込み完了後、「＋ 金魚をお迎え」から名前と種類を選びます。
4. ほかの参加者も、**同じアプリのメッセージ**を開きます。

別々に送信されたアプリのメッセージは別の水槽です。プレゼントを共有するには、全員が1.0.2を使ってください。

### ブラウザでデモを見る

**`アクアリュウム_デモ.html` を保存し、ブラウザで開いてください。**

CSSとJavaScriptを内蔵した単独ファイルです。追加ファイルやサーバーは不要です。サンプルの金魚との交流・プレゼントを体験でき、操作はそのブラウザ内に保存されます。Delta Chatへの送信・共有は行いません。

アプリのソースにある `index.html` は、`style.css`・`core.js`・`app.js` を参照するため、単独ではデモになりません。

## できること

| 機能 | 内容 |
| --- | --- |
| お迎え・命名 | 和金・琉金・出目金から選択。名前は12文字まで、1人3匹まで |
| お世話 | 餌やり・部分換水・水草のお手入れ・そっと眺める |
| 状態・成長 | お腹・水のきれいさ・ごきげん、経験値とレベルを表示 |
| 交流 | ほかの参加者の金魚と一緒に泳ぐ |
| プレゼント | 手紙・金魚の餌・水草・水槽の飾りを贈る |
| 記録 | 最近のお世話・交流と、自分の金魚が贈った／受け取ったプレゼントを表示 |
| バックアップ | 全員の履歴をJSONへ書き出し、別の版へ引き継ぐ |

同じお世話は金魚ごとに5分ごと、一緒に泳ぐ操作とプレゼントもそれぞれ金魚ごとに5分ごとです。操作は共有記録を受信した後に反映されます。

お世話で経験値5、一緒に泳ぐと自分の金魚に10・相手に3が加わります。経験値50ごとにレベルが上がり、レベル2・5で成長段階の表示が変わります。時間がたつと状態は下がりますが、金魚は死なず、経験値も下がりません。

プレゼントのメッセージは300文字までです。手紙には本文が必要です。グッズは状態への効果と記録として残り、水槽に配置する操作はありません。

## バックアップと引き継ぎ

1. 今のアプリで「引き継ぎ」→「JSONを書き出す」を押します。
2. Delta Chatの送信画面で、JSON添付を実際に送信して残します。ボタンを押しただけでは保存完了ではありません。
3. 新しい版の `.xdc` をチャットへ送り、全員が同じメッセージを開きます。
4. 新しいアプリで「引き継ぎ」→「バックアップを選ぶ」からJSONを選びます。
5. 「以前の自分の金魚」で自分の金魚を選び、「この内容で引き継ぐ」を押します。
6. ほかの人も自分の端末で、自分の金魚を選んで引き継ぎます。

新しいアプリのメッセージでは `selfAddr` が変わることがあるため、以前の持ち主と現在の持ち主を対応付けます。「記録だけ読み込む」は持ち主を変更しません。引き継ぐ金魚も1人3匹の上限に含まれるので、新しい金魚を迎える前に引き継いでください。

同じJSONを再度読み込んでも、記録番号で重複を除きます。古いバックアップは今の履歴へ追加され、その後のお世話や経験値を巻き戻しません。

- 専用形式名：`aquaryuum-goldfish-backup`
- 形式番号：`schema: 1`
- 上限：2MB・2万件
- 1.0.1のJSONは1.0.2で読み込めます。
- プレゼントを含む1.0.2のJSONは1.0.1では読み込めません。
- 猫の集会のバックアップは読み込めません。

ブラウザデモの書き出しでは、JSONがダウンロードされます。

## 共有とプライバシー

`webxdc.js` を読み込み、`sendUpdate` と `setUpdateListener` で操作履歴を共有します。状態は履歴と時刻から再計算します。Delta Chat版はブラウザのlocalStorageに依存せず、起動時に共有履歴を読み直します。

**手紙は秘密の個別メッセージではありません。** 名前、持ち主、お世話、交流、プレゼント、手紙本文は同じチャットの参加者に共有され、バックアップにも含まれます。自分の金魚だけを選んで引き継ぎ、信頼できるメンバーで使ってください。暗号署名などによる持ち主の本人確認機能はありません。

## 確認した範囲と制限

独立した複数のブラウザ環境で、お迎え、状態の同期、お世話、交流、手紙と餌の送受信、JSON書き出し・復元、持ち主の変更、再起動、逆順受信、重複防止、分割送信など21項目を確認しました。全4種類のプレゼント処理や不正な記録の拒否は、処理テストでも確認しています。

単独HTMLデモは、ファイルとして開く場合とHTTPで表示する場合の両方で、CSS・金魚・プレゼント操作を確認しています。

- 実機のDelta Chat間の通信と、実際の添付送信・ファイル選択画面は未確認です。
- マニュアルの画面図は模擬環境で撮影しています。
- Word版は文書構造を確認しましたが、Word上の表示・改ページは未確認です。
- ゲーム内のお世話は、実際の金魚の飼育方法を示すものではありません。
